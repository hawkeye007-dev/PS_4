The temporal encoder combines 168 hourly readings and missing flags with each target hour’s calendar, planned schedule, and archived weather forecast. The decoder learns corrections around the prior-week profile; validation checkpoint selection falls back to zero correction when it does not improve that baseline. Train-only fitting; 70/15/15 chronological train/validation/test split. Weather forecasts include seeded lead-dependent error. Peak hours fixed at 12:00–17:59 local before test scoring. Simulated data only; no fabricated outage readings are scored.
